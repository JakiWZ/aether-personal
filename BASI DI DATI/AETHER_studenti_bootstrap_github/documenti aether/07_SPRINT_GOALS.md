# Sprint Goals suggeriti

## Sprint 1 — AETHER FOUNDATION

Obiettivo:
> AETHER possiede una base tecnica condivisa e ogni dominio dimostra almeno un flusso minimo end-to-end.

Risultati attesi:
- modello E-R e schema relazionale v1;
- repository e convenzioni;
- Spring Boot avviabile;
- Angular avviabile;
- prima migrazione SQL;
- dataset seed;
- una vertical slice semplice per squadra;
- PR e review usate realmente.

## Sprint 2 — CORE OPERATIONS

Obiettivo:
> Mission Control può gestire i principali processi operativi e le prime regole di business tra domini.

Focus:
- relazioni tra domini;
- validazioni;
- query con join/aggregazioni;
- transazioni;
- gestione errori;
- componenti Angular;
- integrazione.

## Sprint 3 — INTEGRATED MVP

Obiettivo:
> Consegnare una release dimostrabile e coerente di AETHER.

Focus:
- flussi end-to-end;
- bug fixing;
- refactoring;
- integrazione;
- test;
- dashboard;
- documentazione;
- demo finale.
