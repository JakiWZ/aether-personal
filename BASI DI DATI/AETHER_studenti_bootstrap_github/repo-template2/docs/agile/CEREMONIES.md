# Cerimonie Scrum

## Daily Stand-up — ogni mattina, 10-15 minuti

Ogni studente risponde in massimo 45 secondi:

1. Cosa ho completato dall'ultimo Daily?
2. Cosa farò oggi?
3. Ho impedimenti?
4. Dipendo da un'altra squadra?

Non risolvere i problemi tecnici durante il Daily: registrarli e affrontarli subito dopo.

## Sprint Planning — inizio settimana

1. Product Owner presenta il Goal.
2. Si guardano le Story prioritarie.
3. Gli studenti fanno domande.
4. Verifica Definition of Ready.
5. Planning Poker.
6. La squadra seleziona il lavoro.
7. Le Story diventano `Ready`.
8. Creazione Task tecnici se necessari.

## Backlog Refinement — metà settimana

30-45 minuti:
- chiarire Story future;
- spezzare Story troppo grandi;
- stimare;
- identificare dipendenze;
- rimuovere ambiguità.

## Sprint Review — fine settimana

Ogni squadra mostra software funzionante.

Non presentazioni PowerPoint al posto del prodotto.

Il Product Owner verifica gli Acceptance Criteria.

## Retrospective — fine settimana

Tre colonne:

### START
Cosa iniziamo a fare?

### STOP
Cosa smettiamo di fare?

### CONTINUE
Cosa sta funzionando?

Chiudere con 1-2 azioni concrete per lo Sprint successivo.
