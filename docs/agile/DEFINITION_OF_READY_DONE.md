# Definition of Ready

Una Story può entrare nello Sprint quando:

- [ ] descrive chiaramente un valore o risultato;
- [ ] stakeholder/utente è comprensibile;
- [ ] Acceptance Criteria sono verificabili;
- [ ] dipendenze principali sono note;
- [ ] dati coinvolti sono identificabili;
- [ ] il team comprende cosa deve ottenere;
- [ ] può essere completata in uno Sprint;
- [ ] Story Points sono stati stimati.

# Definition of Done

Una Story è Done soltanto quando:

- [ ] Acceptance Criteria rispettati;
- [ ] codice compilabile;
- [ ] query/migrazioni DB versionate;
- [ ] validazioni implementate;
- [ ] error handling gestito;
- [ ] test pertinenti eseguiti;
- [ ] nessun errore bloccante noto;
- [ ] Pull Request aperta;
- [ ] almeno una Code Review;
- [ ] commenti della review risolti;
- [ ] merge in `main`;
- [ ] documentazione aggiornata se necessaria;
- [ ] righe dei requisiti coperti aggiornate in [`traceability.md`](../requirements/traceability.md);
- [ ] demo della funzionalità possibile.
